# 锋燃 FENGRAN, iOS 健身应用交互原型

一个高保真的 iOS 健身应用交互原型，用纯 HTML/CSS/JS 构建（不依赖任何框架或构建工具），跑在浏览器里模拟 iOS 原生 App 的界面语言和手势交互。数据来自开源 [exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset) 中的真实动作库（名称、目标肌群、器械与分步要领均为原始数据，未做改动），训练计划、日志、社区动态与 AI 教练对话为演示用的虚构内容。动作缩略图与动画 GIF 直接引用自该仓库（`raw.githubusercontent.com`），版权归 [Gym visual](https://gymvisual.com/) 所有，详见下方「素材版权」。

## 为什么是网页原型，不是原生 App

设计与前端技能包的适用范围明确排除了原生移动开发（Apple HIG / SwiftUI 属于另一套工具链）。因此这里交付的是一个可在桌面浏览器里直接点击体验的**高保真网页原型**：用 iPhone 边框、状态栏、标签栏和 iOS 排版规范还原视觉与交互细节，但底层实现是标准 Web 技术，方便快速迭代设计与验证交互逻辑。

## 如何打开

动作图片与 GIF 已改为直接引用 `raw.githubusercontent.com` 上的原始素材，所以 `index.html` 可以直接双击打开，也可以用任意静态服务器访问：

```bash
cd ios-prototype
python3 -m http.server 8934
# 浏览器打开 http://localhost:8934/index.html
```

## 设计系统

| 维度 | 取值 |
|---|---|
| 设计读法 | 健身类 iOS 应用原型，面向大众健身用户，暗色高对比 + 单一强调色，贴近 Apple HIG 的信息层级 |
| DESIGN_VARIANCE | 4（贴近 iOS 系统组件的规整网格与列表，不追求艺术化错位） |
| MOTION_INTENSITY | 6（原生转场、弹簧式反馈、分段指示器跟随、倒计时环，无 GSAP 滚动劫持） |
| VISUAL_DENSITY | 4（标准 App 密度，卡片 + 列表混用） |
| 字体 | 系统字体栈（`-apple-system` / PingFang SC），贴近真实 iOS 渲染 |
| 配色 | 暗色基底（`#0b0b0e` 系）+ 单一橙色强调色（品牌"燃"），与仓库内已有小程序主题一致 |
| 图标 | Phosphor Icons（Regular / Fill / Bold 三套，全局描边粗细统一） |

## 目录结构

```
ios-prototype/
├── index.html      iPhone 设备框 + 状态栏 + 5 个标签的页面结构 + 底部弹层/全屏浮层
├── css/styles.css  设计系统：色彩变量、字体、间距、组件样式、转场动画
├── js/data.js      模拟数据层：动作库、计划、日志、社区动态、AI 教练话术
└── js/app.js       交互逻辑：状态管理、导航栈、渲染函数、事件委托、手势
```

无构建步骤，三个文件通过 `<script>` 标签顺序加载（`data.js` 先于 `app.js`）。

## 五个标签页

1. **首页** — 问候语 + 今日推荐计划卡片（含动作缩略图轮播）+ 一键开始训练 + 本周统计 + AI 教练入口 + 训练量迷你图。
2. **动作库** — 搜索 + 部位横向筛选 chips + 器械筛选半屏弹层 + 动作网格卡片 + 点击进入动作详情半屏卡片（真实动图 + 分步要领）。
3. **训练** — 分段控制（记录 / 计划 / 统计）：
   - 记录：历史训练列表，点击进入详情（容量、组数、动作明细）。
   - 计划：计划卡片列表，点击进入计划详情并可一键开始训练。
   - 统计：周训练量柱状图、连续训练热力图、个人记录 PR 列表。
4. **社区** — 动态信息流（点赞 / 评论数 / 分享），点击进入详情页可查看并发表评论。
5. **我的** — 个人统计卡片 + 功能菜单（计划、记录、收藏、AI 教练、会员、通知、反馈）。

## 关键交互实现

- **导航栈（push / pop）**：每个标签维护独立的屏幕栈（`state.stacks`），`pushScreen` / `popScreen` 驱动 `data-stack-state` 属性在 `entering-from-right` / `active` / `behind` / `exiting-to-right` 之间切换，纯 CSS `transform` 转场，被推到背后的屏幕会轻微缩暗（`brightness(0.7)`），还原 iOS 原生导航控制器的视觉层次。
- **左滑手势返回**：从屏幕左边缘 28px 内按下并向右拖动即可实时拖出上一屏（跟手，非固定动画），松手根据拖动距离判断提交返回或回弹取消，逻辑见 `app.js` 的 `initSwipeBack`。与点击导航栏左上角返回按钮走同一套栈状态机。
- **大标题收起**：用 `IntersectionObserver` 监听页面顶部的哨兵元素，滚动超出视口后为导航栏加上 `is-collapsed`（标题从大标题切换为居中小标题 + 底部分割线），完全不使用 `scroll` 事件监听。
- **底部弹层 / 全屏浮层**：动作详情、器械筛选走 `.sheet`（可拖拽把手，蒙层点击关闭）；训练中和 AI 教练走 `.modal-full`（覆盖整个设备屏幕，包括标签栏）。
- **训练流程**：开始训练后进入沉浸式界面，逐组记录重量/次数（步进器），完成一组自动触发 60 秒组间倒计时环，全部完成后展示训练总结（时长、总容量、完成组数、个人记录提示）。
- **AI 教练对话**：预置快捷提问 chips，发送后展示打字动画（三点跳动），延迟后给出针对性回复；可自由输入文本。
- **点赞 / 评论**：即时切换点赞状态与计数，评论支持本地追加，无需刷新页面。

## 已知的原型边界

- 所有网络请求、鉴权、支付等均不存在，训练数据、社区动态和统计数字为写死的演示内容，刷新页面会重置为初始状态。
- 部分次要菜单项（会员中心、通知设置、发布动态、新建计划）仅弹出提示条，未做深层实现，属于原型阶段的合理留白。
